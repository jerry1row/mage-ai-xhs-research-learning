# AI博主研究学习册 · 几何研究室

马哥赢创的16章AI博主研究学习网页。适合内容创作者、个人IP与一人经营者，学习市场调查、对标、内容制作、商单、虚拟产品与经营复盘。

## 阅读

[在线学习网页](https://jerry1row.github.io/mage-ai-xhs-research-learning/)

- 浏览器打开 index.html，或者使用静态HTTP服务。
- 手机和平板采用响应式布局；宽表格在局部区域内滑动。
- 学习目录、搜索、字号、原文重点、练习、自测和进度均可在浏览器内使用。
- 来源原文需要对应网站的访问权限。

学习记录只保存在当前浏览器与当前站点；切换设备不会自动同步。可在“我的学习记录”中导出JSON备份。网站不上传学习笔记，不接入第三方跟踪脚本。

## 内容

16章详细方法、16张知识图解、16组重点/练习/自测、12篇生财来源的学习地图、4本航海手册指引、8条分析提示词、12张空白CSV研究表、完整教学示范和30天行动计划。

示范数字和评分权重为教学用途；来源作者经营成绩是历史自述。平台资格与商品类目按实际后台核验。

## 运行

这是原生静态网页，不需要构建、不依赖CDN。GitHub Pages可从包含index.html的分支根目录提供页面。

页面内容与目录定位修复已经所有者审核，并授权发布。
